# LearnPath AI — Demo Video Script (3–5 min)

**App:** https://frontend-mu-jet-18.vercel.app
**Goal:** Show the ALGORITHMIC brain (AI/ML = 20%), the 6 required features (Functionality = 25%), and explainability (Innovation). Do NOT just scroll the UI — narrate the WHY.

---

## 0:00–0:30 — Hook + Problem (30 sec)
**Screen:** Landing page
**Say:** "Online platforms show you 50 Python courses, but never the right ORDER. LearnPath AI doesn't recommend a pile of courses — it builds you a sequenced roadmap based on YOUR skills, goals, and skill gaps."

---

## 0:30–1:15 — Conversational Profiling (45 sec)
**Screen:** Click "Start Learning Journey" → chat onboarding
**Say:** "The assistant asks natural questions — your field, experience, weekly time, and goal. This builds a learner profile: interests, level, completed skills, and objectives — exactly what the problem statement asks for."
**Show:** Select "Machine Learning & AI", "Intermediate", "10-20 hours", "Career change to tech".

---

## 1:15–2:00 — The Algorithmic Core (THE key part) (45 sec)
**Screen:** Click to Learning Path → show the generated path
**Say:** "Here's the part that's real AI/ML, not a wrapper. The system holds a 65-skill knowledge graph. It computes your skill gaps as a set difference — target career skills minus your current skills. Then it runs a **topological sort** over the graph so you always learn prerequisites FIRST — Python before NumPy before Machine Learning."
**Show:** Expand Phase 1 → "see, Python comes first because ML requires NumPy and statistics, which require Python."
**Mention:** "Now every phase also includes **Projects and Assessments** — a complete roadmap of courses, projects, and checks."

---

## 2:00–2:40 — Explainable Recommendations (40 sec)
**Screen:** Click "Why this?" / open a course explanation; open the Algorithm page
**Say:** "Every recommendation is explained — not by an LLM hallucinating, but by a rule-based engine reading the graph. It tells you how many prerequisites this skill needs and what it unlocks downstream."
**Show:** Open `/algorithm` page → "Here's the 5-factor scoring live: skill gap 35%, career relevance 25%, ML similarity 20%, difficulty fit 10%, prerequisites 10%. Transparent, deterministic, explainable."

---

## 2:40–3:10 — Chat + Gemini (30 sec)
**Screen:** Chat page, ask "Why Python before ML?" and "How long will this take?"
**Say:** "Ask the assistant anything — it answers from the graph, and an optional Gemini layer polishes it into natural language. But here's the key: **remove Gemini entirely and the whole system still works.** That's resilience."

---

## 3:10–3:45 — Dashboard / Progress / Feedback (35 sec)
**Screen:** Dashboard → mark a skill "Too Easy"
**Say:** "The dashboard visualizes your progress, skill coverage, and next action. Give feedback — 'Too Easy' or 'Too Hard' — and the path re-ranks in real time. That's adaptive learning."

---

## 3:45–4:20 — Skill Graph + Clickable Courses (35 sec)
**Screen:** Skill Graph page → interactive DAG; click a skill; then open a course link (new tab)
**Say:** "This is our 65-skill interactive graph. And every course is a real, clickable resource — NPTEL, SWAYAM, freeCodeCamp, Coursera — with India-specific free resources prioritized."

---

## 4:20–4:45 — Close (25 sec)
**Screen:** Skill graph or landing
**Say:** "LearnPath AI — curriculum sequencing, explainable recommendations, adaptive feedback. Built as a robust client-side engine with a Python ML backend, 22 automated tests, and designed for real Indian learners. Thanks for watching."

---

## Delivery Tips (make or break the score)
1. **Talk over every click** — say the WHY, not just what's on screen.
2. **Highlight the words: topological sort, skill gap, 5-factor scoring, works without an LLM** — these map directly to AI/ML (20%).
3. Use **"Priya — Aspiring Data Scientist"** demo profile from the Dashboard to skip straight to a populated app.
4. Keep it **3:30–4:45** — under 5 min is safe, over is cut off.
5. Record with clear audio + normal fonts; zoom in on the Algorithm page — it's unique and impressive.
